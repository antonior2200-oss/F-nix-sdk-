# # Fénix SDK 🔥  
Sistema modular para percepción asíncrona, procesamiento de visión y gestión de eventos en tiempo real.

Fénix SDK es un framework ligero y extensible diseñado para construir sistemas de visión por computadora basados en loops asíncronos, pipelines de procesamiento y reactores de eventos. Su objetivo es ofrecer una arquitectura clara, modular y fácil de extender para proyectos de IA, robótica, vigilancia, análisis de vídeo y más.

---

## 🚀 Características principales
- **VisionLoop**: bucle asíncrono de captura y procesamiento de frames.
- **Reactor de detecciones**: sistema de eventos para reaccionar a detecciones en tiempo real.
- **Arquitectura modular**: fácil de extender con tus propios módulos.
- **Ejemplos incluidos**: casos prácticos para empezar rápido.
- **MIT License**: libre para uso personal y comercial.
